# 📱 新加坡＆迪士尼郵輪行程指南 - 離線 PWA App 版本

此資料夾 `pwaoffline/` 是特別為**出國離線使用**所建構的完整 Progressive Web App (PWA)。

---

## 🌟 核心特點

1. **出國零流量秒開（Service Worker 離線快取）**：
   - 包含 `manifest.json` 與 `sw.js`。
   - 在出國前連線開啟一次後，所有核心頁面、圖示與影音素材會自動被手機快取，之後即使飛航模式、無網路也完全能順暢開啟。
2. **內建「拍攝示範燈箱（Lightbox）」**：
   - 避開手機相簿權限與無法定位的問題。
   - 在每個拍攝任務旁皆有「🎬 示範」按鈕，點擊立即在 App 內彈出預覽。
   - 支援 **自動循環播放（Loop）**、**0.5x 慢動作播放**（拆解動作超方便）、**拍攝要點指引**。
3. **子項目自動連動完成**：
   - 子選項全勾滿 ➔ 卡片自動標記完成。
   - 當天行程 100% 打卡 ➔ 頂部 Day 頁籤自動標記 `✓ 完成`。
4. **手機全螢幕獨立 App 體驗**：
   - 在 iPhone（Safari）或 Android（Chrome）點擊「加入主畫面」，即可作為獨立 App 執行，無上方網址列與下方工具列。


## 🚀 如何在手機上「安裝為離線 App」？

### 🍏 iPhone (iOS Safari)
1. 用 Safari 開啟此網頁。
2. 點擊瀏覽器底部的 **「分享按鈕（方框加向上箭頭 ⎋）」**。
3. 下拉選單選擇 **「加入主畫面」**（Add to Home Screen）。
4. 桌面上就會出現「星國迪士尼」專屬 App 圖示，點開即是乾淨的全螢幕 App！

### 🤖 Android (Google Chrome)
1. 用 Chrome 開啟此網頁。
2. 點擊右上角「三個點選單」。
3. 選擇 **「安裝應用程式」** 或 **「新增至主螢幕」**。
4. 安裝完成後即可離線點擊啟動。

## 🎬 如何放入 IG 影片或截圖？

請參閱 `pwaoffline/media/README.md`：
- 將下載好的 IG Reels MP4 影片命名為對應編號（例如 `t1-2.mp4`）放入 `media/` 資料夾。
- 也支援直接放定格截圖（`t1-2.jpg`）。
- 網頁會自動偵測並秒開播放！
